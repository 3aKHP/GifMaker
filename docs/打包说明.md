# 频闪梗图生成器 - 打包说明

## 方法一：使用批处理脚本（推荐）

直接双击运行 `packaging/build_exe.bat`，脚本会自动完成所有步骤。

## 方法二：手动打包

### 1. 安装PyInstaller

```bash
pip install pyinstaller
```

### 2. 基础打包命令

```bash
pyinstaller --onefile --windowed --name "频闪梗图生成器" src/strobe_meme_generator.py
```

### 3. 高级打包命令（轻量化）

```bash
pyinstaller --noconfirm ^
    --onefile ^
    --windowed ^
    --name "频闪梗图生成器" ^
    --hidden-import=PIL.ImageTk ^
    --exclude-module imageio ^
    --exclude-module numpy ^
    --exclude-module matplotlib ^
    --exclude-module cv2 ^
    src/strobe_meme_generator.py
```

### 4. 参数说明

- `--onefile`: 打包成单个exe文件
- `--windowed`: 不显示控制台窗口（GUI程序）
- `--name`: 指定exe文件名
- `--hidden-import`: 添加隐藏导入
- `--exclude-module`: 排除误收集的大型依赖
- `--icon`: 指定图标文件（可选）

### 5. 输出位置

打包完成后，exe文件位于 `dist` 目录下。

## 方法三：使用spec文件（高级）

### 1. 生成spec文件

```bash
pyi-makespec --onefile --windowed --name "频闪梗图生成器" src/strobe_meme_generator.py
```

### 2. 编辑spec文件

打开 `packaging/频闪梗图生成器.spec` 文件，可以进行更详细的配置。

### 3. 使用spec文件打包

```bash
pyinstaller packaging/频闪梗图生成器.spec --distpath dist --workpath build
```

## 常见问题

### Q1: 打包后运行报错找不到模块

**解决方案**: 使用 `--hidden-import` 参数添加缺失的模块

```bash
--hidden-import=PIL.ImageTk
```

### Q2: 打包后字体显示异常

**解决方案**: 默认优先读取系统字体；如果需要做“跨机器便携版”，再使用 `--add-data` 参数包含字体文件

```bash
--add-data "C:/Windows/Fonts/simhei.ttf;."
```

### Q3: exe文件太大

**解决方案**: 
1. 使用干净的 `venv`，只安装 `Pillow` 与 `PyInstaller`
2. 使用 `--exclude-module` 排除 `imageio/numpy/matplotlib/cv2`
3. 考虑使用 `--onedir` 代替 `--onefile`

### Q4: 打包后启动慢

**解决方案**: 
- `--onefile` 模式会先解压到临时目录，启动较慢
- 改用 `--onedir` 模式可以加快启动速度

## 优化建议

### 1. 创建虚拟环境

```bash
py -3.10 -m venv .venv-pack
.venv-pack\Scripts\activate
pip install pillow pyinstaller
```

### 2. 在虚拟环境中打包

这样可以显著减小 exe 文件大小，避免把 Conda 里的可选科学计算/多媒体依赖一起打进去。

### 3. 添加图标

准备一个 `.ico` 文件，然后使用：

```bash
--icon=icon.ico
```

### 4. 压缩exe

使用UPX压缩工具：

```bash
pip install pyinstaller[encryption]
pyinstaller --upx-dir=upx路径 ...
```

## 分发建议

1. **单文件模式** (`--onefile`): 适合简单分发，但启动较慢
2. **目录模式** (`--onedir`): 启动快，但需要分发整个文件夹

4. **测试**: 在干净的Windows系统上测试exe是否能正常运行
