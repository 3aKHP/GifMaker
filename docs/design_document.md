# 项目设计文档：频闪梗图生成器 (Strobe Meme Generator)

## 1. 项目概述
这是一个用于生成“快速闪烁文字”动图的桌面工具。用户输入一段包含“变量”的文本模板，程序自动生成所有可能的组合，并按照特定的顺序（随机或平滑过渡）合成 GIF 或 WebP 动图。
这种图片常用于“截图选老婆”或“测测你今天的状态”等网络迷因。

## 2. 核心功能需求

### 2.1 文本模板解析 (Meme Syntax)
用户输入的文本支持通过花括号 `{}` 定义闪烁位，使用 `/` 分隔选项。
*   **输入示例**：`白{神/区}{神/区}了`
*   **解析逻辑**：
    *   固定文本：`白`，`了`
    *   闪烁位 1：`["神", "区"]`
    *   闪烁位 2：`["神", "区"]`
*   **复杂示例**：`今天{吃/喝/玩}{火锅/奶茶/原神}` (支持任意数量的选项和任意数量的闪烁位)。

### 2.2 闪烁模式 (Sequence Algorithms)
程序需要支持两种生成帧序列的模式：

1.  **完全随机 (True Random / Equal Probability)**
    *   生成所有可能的组合（笛卡尔积）。
    *   将列表完全打乱 (`shuffle`)。
    *   保证在一个循环周期内，每种组合出现且仅出现一次（等概率）。

2.  **平滑模式 (Gray Code / Hamming Distance = 1)**
    *   **核心目标**：相邻的两帧之间，**只能有一个闪烁位发生变化**。这能产生一种机械的、顺滑的视觉效果。
    *   **算法提示**：对于非二进制的选项（如3个选项），需要实现“广义格雷码”或“混合基数格雷码”逻辑。
    *   *示例*：如果是两个位，每个位有3个选项 (0,1,2)，序列应该是 `00 -> 01 -> 02 -> 12 -> 11 -> 10 -> 20...` (确保每次只变一位)。

### 2.3 输出格式控制
*   **GIF**：支持设置帧延迟（秒）。注意处理 GIF 的 0.02s 最小延迟限制。
*   **WebP**：支持设置帧持续时间（毫秒）。

### 2.4 图形界面 (GUI)
建议使用 Python 内置的 `tkinter` 以保证兼容性（或者使用 `customtkinter` 如果环境允许）。
界面应包含：
*   **输入区**：文本框输入模板字符串。
*   **参数设置区**：
    *   字体大小 (Font Size)
    *   图片尺寸 (Width, Height)
    *   帧持续时间 (Duration in ms)
    *   模式选择 (Random / Gray Code)
    *   背景色/文字色选择 (Color Picker)
*   **操作区**：
    *   “生成预览”按钮（可选，生成第一帧静态图）。
    *   “导出 GIF”按钮。
    *   “导出 WebP”按钮。
*   **状态栏**：显示生成进度或成功提示。

## 3. 技术实现细节

### 3.1 字体处理
*   复用 `white_gif.py` 中的字体查找逻辑。
*   自动扫描系统常用中文字体（SimHei, Microsoft YaHei, PingFang 等）。
*   如果在 GUI 中能让用户选择字体文件最好，否则使用自动匹配。

### 3.2 图像绘制
*   使用 `Pillow (PIL)` 库。
*   **关键点**：必须保持字符位置固定。
    *   不能简单地将整行字符串居中绘制，否则当字符宽度不一致时（如“1”和“W”），左右两侧的固定文本会发生抖动。
    *   **算法**：计算整个字符串的总宽度，确定起始 X 坐标。然后逐个字符绘制，每个字符的 X 坐标是固定的（基于预设的字间距或等宽处理）。或者，将画布水平均分给每个字符（如 `white_gif.py` 中的做法）。

### 3.3 广义格雷码算法参考
如果用户输入了 N 个闪烁位，每个位有 $M_i$ 个选项。
生成序列的递归逻辑：
1.  生成第一位的序列 $0 \dots (M_0-1)$。
2.  对于下一位，如果是偶数行，顺序遍历 $0 \dots (M_1-1)$；如果是奇数行，逆序遍历 $(M_1-1) \dots 0$。
3.  以此类推，确保相邻元素只有一位变化。
